# 📚 ManageYourLibrary

**ManageYourLibrary** is a web-based Library Management System designed to make book tracking, user management, and loan handling simple and efficient.  
This project provides a clean, responsive dashboard for administrators, librarians, and general users.

---

## 🚀 Features

### 👤 User Roles
- **Admin** – Full access (manage books, loans, and users)
- **Worker** – Manage books and loans
- **Guest** – View available books only

### 📘 Books Management
- View and search books by title or author  
- Add, edit, and delete books  
- Track available and total copies  

### 📄 Loan Management
- Create and manage book loans  
- Track borrower, borrowed date, due date, and return status  

### 👥 User Management
- Add and manage library users  
- Assign user roles and passwords
